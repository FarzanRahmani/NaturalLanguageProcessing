# من قصد دارم اطلاعات مربوط به رویدادهای تاریخی مهم ایران (شامل جنگ‌ها، قراردادها، انقلاب‌ها، دستاوردها) را در ساختار JSON با فرمت مشخص و استاندارد ذخیره کنم. لطفاً متن تاریخی که به تو می‌دهم را به ساختار JSON زیر تبدیل کن. بیا مرحله به مرحله این کار را انجام دهیم:

### دستورالعمل‌های دقیق و مرحله به مرحله:
1. **زبان محتوا**:حتما تمام فیلدهای JSON را با فارسی پر کن.

2. **ساختار استاندارد JSON** (این ساختارها ثابت هستند و نباید آن را تغییر بدهی):


ساختار جیسون برای جنگ‌ها:


```
WAR_JSON_STRUCTURE_PLACEHOLDER
``` 

ساختار جیسون برای قرارداد‌های تاریخی:

```
CONTRACTS_JSON_STRUCTURE_PLACEHOLDER
```

ساختار جیسون برای انقلاب‌ها:

```
REVOLUTIONS_JSON_STRUCTURE_PLACEHOLDER
```

ساختار جیسون برای دستاورد‌ها:

```
ACHIEVEMENTS_JSON_STRUCTURE_PLACEHOLDER
```


3. **توجه بسیار زیاد به موارد زیر**:
   - محتوایی که من به تو می‌دهم در قالب یکی از موضوعات [جنگ‌، قرارداد، انقلاب‌، دستاورد] است. این که درباره کدام یک از این موارد است را خودت باید تشخیص بدهی و متناسب با آن ساختار مناسب آن را انتخاب کنی. در واقع باید فقط یکی از ساختار های بالا را برای متن داده شده انتخاب کنی. در بالا تمام ساختار های ممکن برای این موضوعات را قرار داده‌ام. دقت کن که صرفا باید یک ساختار جیسون تکمیل شده با استفاده از متن داده شده را در خروجی قرار دهی. لطفا به جز ساختار جیسون خروجی، هیچ مورد دیگری در خروجی قرار نده.
   - اگر اطلاعاتی برای یک فیلد موجود نبود، مقدار null (برای اعداد) یا رشته خالی "" (برای متن) قرار بده.
   - برای مقادیر عددی که نامعلوم هستند از null استفاده کن (نه صفر).
   - ساختار JSON باید کاملاً معتبر باشد و با json.loads() در پایتون قابل پردازش باشد.
   - در پر کردن فیلد هایی که نیاز به توضیح است باید توضیحات کامل و جامع باشد و از خلاصه کردن آنها خودداری کن. همچنین سه نقطه (...) قرار نده.
   - برای هر یک از فیلدها توضیحاتی در مقابل آنها آمده است. در ساختار خروجی نباید این توضیحات وجود داشته باشد.
   - نکته بسیار مهم: در خروجی ابتدای شروع ساختار جیسون عبارت START_JSON قرار بگیرد و در انتهای ساختار جیسون عبارت END_JSON قرار بگیرد. دقت کن که صرفا باید یک ساختار جیسون در خروجی قرار دهی. لطفا به جز ساختار جیسون خروجی، هیچ مورد دیگری در خروجی قرار نده.
   - سعی کن تا جایی که می‌ توانی اطلاعات مورد نیاز برای تکمیل ساختار جیسون را از متنی که به تو میدهم استخراج کنی. برخی از اطلاعات به صورت صریح بیان نشده است، اما باید آنها را از متن به صورت ضمنی استخراج کنی. اما اگر در متن داده شده اطلاعات مفیدی درباره یک فیلد نبود، آن را به شکلی که گفته شد (مقدار null (برای اعداد) یا رشته خالی "" (برای متن)) پر کن.

   
   




5. **نمونه خروجی مورد انتظار**:




نمونه ساختار تکمیل شده برای یکی از جنگ‌های تاریخی:

```
SAMPLE_JSON_OUTPUT_WAR_PLACEHOLDER
```




به عنوان نمونه ساختار تکمیل شده برای یکی از قراردادهای تاریخی به صورت زیر است:

```
SAMPLE_JSON_OUTPUT_CONTRACTS_PLACEHOLDER
```





به عنوان نمونه ساختار تکمیل شده برای یکی از انقلاب‌های تاریخی به صورت زیر است:

```
SAMPLE_JSON_OUTPUT_REVOLUTIONS_PLACEHOLDER
```




به عنوان نمونه ساختار تکمیل شده برای یکی از دستاورد‌های تاریخی به صورت زیر است:   

```
SAMPLE_JSON_OUTPUT_ACHIEVEMENTS_PLACEHOLDER
```


   

6. حالا لطفاً متن زیر را به ساختار JSON تبدیل کن:

QUERY_CONTENT_PLACEHOLDER
